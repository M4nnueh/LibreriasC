# LibreriasC

Repositorio en GitHub para las librerías que se usarán en el aplicativo web.     

Repo de el proyecto:
https://github.com/M4nnueh/Proyecto_analisis_numerico

## Autores
- Manuel Alejandro Ramirez Bravo
- Nicolas Lozano Salazar

## Contenido
- **`binarios.c`**: Conversión entre números decimales y binarios (y viceversa).
- **`Biseccion.c`**: Método numérico de Bisección para hallar raíces en un intervalo [a, b].
- **`iteracion.c`**: Método de iteración / punto fijo para encontrar raíces de ecuaciones no lineales.
- **`newton.c`**: Método de Newton-Raphson para aproximaciones numéricas a las raíces de funciones reales.
- **`redondeo.c`**: Cálculo de error absoluto y error relativo.
- **`taylor.c`**: Aproximación de la función e^x mediante polinomios de Taylor.
